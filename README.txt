KIDS GALLERY SHOPPING WEBSITE
=============================

Files
-----
index.html  - Website structure
style.css   - Styling and responsive layout
script.js   - Product search, category filters, cart, quantity and totals

How to run
----------
1. Extract KidsGallery.zip.
2. Open the extracted KidsGallery folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Internet is needed for the placeholder product images and Google Fonts.

Features
--------
- Kids clothing product catalogue
- Search by product name
- Boys, Girls and Baby category filters
- Add items to cart
- Increase/decrease quantity and remove items
- Automatic total calculation
- Responsive mobile layout

Note
----
This is a frontend demonstration project only. It has no backend, database,
user login, real checkout, or payment processing.
